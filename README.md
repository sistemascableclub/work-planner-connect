# Work Planner Connect

Crea una landing page de reclutamiento moderno para "Work Planner", una agencia de talento especializada en perfiles de Ventas y Marketing. El diseño debe ser minimalista, profesional y estrictamente "mobile-first", usando una paleta de colores azul corporativo con acentos dinámicos en naranja o amarillo.

La página debe contener:

Un Hero Section atractivo con el título "Encuentra tu próximo desafío en Ventas o Marketing" y un botón principal de "Postular ahora".

Una sección principal que contenga un Formulario de postulación tipo Wizard (multi-paso) dividido en 3 etapas: Paso 1 (Datos Personales básicos), Paso 2 (Nivel de estudios y Experiencia laboral) y Paso 3 (Carga de CV y pretensiones salariales).

La interfaz del formulario debe sentirse muy fluida, con un indicador de progreso visual y botones grandes de "Siguiente" y "Atrás", optimizada para reducir el abandono de postulantes
